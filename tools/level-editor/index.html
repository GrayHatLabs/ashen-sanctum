Get started

1. Export the game's current maps once (they become your starting points):

wsl -d Ubuntu -e bash /mnt/d/projects/AshenSanctum/scripts/dev-build.sh run --export-levels levels/generated

2. Click Open levels folder and pick D:\projects\AshenSanctum\levels. Pick a map from the list (generated ones are marked), edit it, and Save: it's written to levels/<name>.json, which the game uses instead of the generated map.

3. Test it: ... dev-build.sh run --level bone_crypt_floor1

No folder access (Firefox)? Use Open file… and Download, then put the file in levels/. You can also drag a .json onto this page.
