# Fire skills plan

Agreed 2026-10-01. Defaults taken because the user didn't pick: D2-style skill points,
cooldowns allowed on attack skills (not movement), no fire-immune enemies for now.

## Getting skills

- 1 skill point per character level, plus 1 per Warden's Seal.
- Tiers unlock at character level 1 / 6 / 12 / 18; some skills need a prerequisite.
- Ranks 1-10 per skill (more damage and size). Synergies boost related skills.
- Brother Aldric resets skill points for gold.

## Skills

| Tier | Skill | What it does |
|---|---|---|
| 1 | Fireball | Exploding bolt, splash, burning (exists) |
| 1 | Inferno | Hold: short flame cone, mana per second |
| 1 | Warmth (passive) | +% mana regeneration |
| 2 | Fire Nova | Ring of fire around you, knockback |
| 2 | Fire Wall | Line of flames that burns anything crossing it |
| 2 | Blaze | Leave a fire trail while moving for a few seconds |
| 3 | Combust | Detonate burning enemies nearby |
| 3 | Meteor | Telegraphed meteor (1 s), burning ground |
| 3 | Fire Mastery (passive) | +% fire damage, longer burns |
| 4 | Hydra | Fire hydra turret for 10 s |
| 4 | Ash Phoenix | 6 s of speed and free casts, explosion when it ends |

Synergies: Meteor boosts Fireball, Fire Mastery lengthens Blaze, Fire Wall boosts Combust.

## Controls

- Two slots, like D2's left and right skills.
- **Mouse:** right click = secondary, Shift / left-click a monster = primary, 1-4 pick the secondary, K opens the skill tree.
- **Pad:** A = primary, X = secondary, R1 cycles the secondary, hold SELECT for the skill tree (tap = map).
- Out of mana, any cast falls back to the free Ember Bolt.
